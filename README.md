# TraeSign

Trae（TraeWork / Trae SOLO CN / Trae CN）**每日自动签到托盘助手**：常驻系统托盘，每天自动完成签到领取积分，并在日历中记录每一天的签到结果。

程序本体仅 `TraeSign.exe` 一个文件（约 40KB），全部功能内置，**无需安装任何运行环境**。

## 功能特性

- 自动签到：每天 00:05 自动签到当前选中账号，失败按 5/15/30/60/120 分钟递增重试
- 多账号：自动读取本机 TRAE SOLO CN / Trae CN / TraeWork 的登录态，可切换签到账号
- 托盘状态：图标颜色实时反映签到状态（灰=未签到 / 绿勾=已签到 / 红=异常）
- 签到日历：自绘月历，绿色标记签到成功日，可翻月查看
- 二次确认：签到成功后复查服务端状态，杜绝 token 过期导致的"假成功"

## 快速开始

1. 双击运行 `TraeSign.exe`（首次运行被 Defender 拦截属正常，程序无数字签名，点"仍要运行"）
2. 程序缩到系统托盘，图标变绿勾即今日已签到
3. 双击托盘图标打开主窗口，查看账号 / 积分 / 签到日历

详细说明（自动签到、多账号限制、开机自启、常见问题）见 [使用说明.md](使用说明.md)。

## 从源码编译

```
compile.bat
```

依赖 Windows 自带的 .NET Framework 4.8（`csc.exe`），零 NuGet 包，输出单文件 `TraeSign.exe`。

| 源文件 | 说明 |
|---|---|
| `TraeCheckinApp.cs` | 主程序（托盘、调度、签到接口、登录态解密） |
| `CalendarControl.cs` | 自绘签到日历控件（GDI+） |

## 数据说明

- 签到历史：`%APPDATA%\TraeCheckin\history.json`（本地记录，删除即清空）
- 程序**只读** Trae 的登录态文件，不修改、不上传登录凭证

## 限制

同机多个 Trae 软件共享设备 ID，服务端限制**每天仅一个账号可签到成功**，属服务端规则，非程序问题。
